online_bookstore :

A SQL project built in MYSQL to analyze an online bookstore’s sales, customers and inventory.

About the project :

I created a database with three tables (Books, Customers and Orders), loaded the data from CSV files, and wrote SQL queries to answer business questions like which genres sell the most, who the top customers are, and how much stock is left after orders.

Skills used :

Filtering, joins, GROUP BY and HAVING, aggregate functions, COALESCE, LEFT JOIN
